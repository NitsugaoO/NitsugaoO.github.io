## 改完怎么生效

### ⚠️ `scripts/` 下的脚本改完必须重启 hexo server

`source/js/` 下的改动 server 会自动重载，但 **`scripts/` 目录的站点脚本
只在进程启动时加载一次**。改了 `scripts/library-data.js` 却不重启，
`hexo server` 会用旧逻辑生成 JSON（表现为“数据里新字段全是空的”，
但直接跑 `hexo generate` 产物又是对的——容易迷惑人）。

```bash
bash "scripts/sync.sh" --serve   # 改完 scripts/ 就跑这个
```

### ⚠️ 改 `_config*.yml` 也要重启，不只是 regenerate

`hexo server` 对**已渲染过的页面有缓存**。改 `_config.yml` / `_config.butterfly.yml` 后
只跑 `hexo generate` 的话：`public/` 里的确是新内容，但 `localhost:4000` 返回的还是旧的
（改站点 `title` 时踩过，一度以为配置没生效）。

```bash
bash "scripts/sync.sh" --restart   # 只重启预览服务器
bash "scripts/sync.sh" --serve     # clean + generate + 重启（更保险）
```

### 网页字体：`tools/build-fonts.py`

字体是**子集化 + 分片**的（细节见 [`01-配色与样式.md`](01-配色与样式.md) 「网页字体」节）。
改了文章正文、引入了新的生僻字时，要重跑：

```bash
python tools/build-fonts.py      # 约 40 秒，重扫全站字符 → 重写 source/fonts/ 与 source/css/fonts.css
pnpm exec hexo generate          # 字体文件变了，要重新生成
```

管理页 `?view=fonts` 会直接告诉你有没有缺字，点「重新生成子集」等价于上面第一条。
依赖：`pip install fonttools brotli`。脚本会跳过 fenced 代码块 / `{% raw %}` / 行内代码
—— 那是文档示例，不能改。



```bash
# 1. 重新生成（改了 css / _config 后必须做，否则看不到变化）
cd /c/Users/Agustin/blog && pnpm exec hexo generate

# 2. 提醒用户 Ctrl+Shift+R 强制刷新
#    普通 F5 会读缓存的旧 CSS，看起来像"改动没生效"
```

## 发布上线

**发布 = `add` + `commit` + `push`，三步缺一不可。**

只 commit 不 push，两个平台都拉不到代码 —— 它们监听的是**远程仓库**。
（已经犯过一次这个错，所以用脚本防呆。）

```bash
bash "scripts/sync.sh" "commit 描述"
```

推送后 1~2 分钟自动部署。检查构建状态：

```bash
gh run list --limit 3                      # GitHub Pages
gh run view <run-id> --json status,conclusion
```

## 不能碰的约束

| 约束 | 原因 |
|---|---|
| **仓库名固定 `NitsugaoO.github.io`** | GitHub 只有识别这个名字才会把站点发布到**根路径**。改成普通名字会变成 `/仓库名/` 子路径，与 Cloudflare 的根路径冲突，导致 CSS/JS 全部 404 |
| **`url` 只能填一个平台** | 决定 canonical / RSS / sitemap，当前填 Cloudflare 地址 |
| **workflow 里不能写 pnpm 的 `version`** | 与 `package.json` 的 `packageManager` 冲突，会导致 `Setup pnpm : failure` |
| **Cloudflare 需要 `NODE_VERSION=22`** | 默认 Node 版本过旧，Hexo 8 构建会失败 |
| **不修改 `themes/butterfly/`** | 所有定制放 `source/css/everforest.css`，保证主题可以 `git pull` 升级 |

## 常用命令

```bash
cd /c/Users/Agustin/blog

pnpm exec hexo generate     # 生成
pnpm exec hexo clean        # 清缓存（改过配置后建议先 clean）
pnpm exec hexo server       # 本地预览 http://localhost:4000
pnpm exec hexo new "标题"    # 新建文章
python tools/build-fonts.py  # 新增生僻字后重建字体子集（约 40 秒）
```

脚本还提供：

```bash
bash "scripts/sync.sh" "描述"      # 发布（add + commit + push）
bash "scripts/sync.sh" --serve    # 重新生成 + 重启预览服务器
bash "scripts/sync.sh" --restart  # 只重启预览服务器
bash "scripts/sync.sh" --check '#色值'   # 查色值残留（诊断用）
```
