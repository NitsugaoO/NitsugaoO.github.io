## 笔记本电脑

![](/images/40165c75a0.png)

用的机器是我非常满意的 **联想 ThinkBook 14+**，2026 年新款。在高考到来前，5 月底的时候，蹲了 618 的一个活动优惠。是从京东上买的，目前价格应该比我买的价格高 2500 RMB；然鹅我买的价格也比首发能拿到的最低价高 1500 RMB。你就涨吧，what can I say。

tmp: 硬件信息插入.fold

参数一堆不赘述，笔吧.link。我主要会讲一些实际体验上满意的点吧。我说白了，这个价钱在讲完价钱之后我基本只剩下夸了吧。

显著的感受是**续航特别长**！目前一直开着电池保护模式，最高只会充到 80%，在开启系统的节能模式和 Lenovo Vantage 的静音省电模式的时候，开着 5 个 Edge 标签页，WSL，VSCode，Wallpaper Engine 暂停，亮度 50%（我发现实际上对这台机器续航影响最大的似乎也就是亮度了）可以用 7 个小时左右。注意这是 80% 的电量。PTL 是对的，你们知道吗！根据我天天课上耍电脑的测试，妥妥用一天。

在 14+ 和 16+ 之间选了很久。我的上一台电脑是 ASUS VivoBook15 2021，重 1.7kg，16 寸（实际上屏幕比标准的 16 寸小，说是 15.3 寸好像），是有数字小键盘的。我矛盾的点就在于
1. 14+ 和 16+ 完全是一个价格。还挺神奇的；
2. 14+ 没有数字小键盘；
3. 16+ 比上一台电脑重，我想要至少比上一台轻的。

思索再三之后感觉轻是对的，而且未来感觉会买外置键盘；实际上 TB 14+ 的屏幕也比 14 寸大点，宣传是 14.几 忘记了，实际上 16:10 的屏幕对比一下旧电脑当然是直接喵鲨了；1.5kg 直接变成使用者的一部分；并且很快就适应了没有数字小键盘，毕竟之前用小键盘好像主要就是在输密码了：但是这个需求被人脸和指纹斩杀了（既有人脸又有指纹！）。此外功能键也很齐全了， home / end / delete / page up / page down 都有。

这个键盘很值得一提。我的天呐这个小全高方向键是左上右上夹着翻页键简直是天才的布局！

fold_begin
我的打字习惯完全是全靠自己领悟的，怎么说呢，我的左手（正如同我打 Phigros 的时候一样只有左手有多指力）会接管整个 J 键左侧的按键，我的右手食指 idle 状态就放在 K 键上，用右手无名指点 Backspace。真是毁了啊！回溯一下感觉是小学初学 OI 的时候打了大量的 ```#include``` 到 ```return 0; }``` 导致的，初次发现自己似乎能半盲打的时候大概就是发现自己可以极快的打完模板的时候。那个时候还不知道 ```#include``` 是在做什么。感慨。
fold_end

tmp: vantage.pic

静音 / 禁用麦克风 / 大写锁定 / fn lock 都是有小灯指示的。

tmp: Keyboard.pic，背光开关

但唯一的缺点你也可以从图中看出：这个键盘打油。

X7 358H 的处理器 / Arc B390 集成显卡当然是重点。具体参数不在此赘述，讲一讲大致的实际表现吧：续航上面提到了，在打游戏的时候，丝之歌和蔚蓝这两个小东西当然是没有任何压力了。MC 可以 1920 * 1200 开 Complementary Shader High Preset 跑满 90 fps。绝区零浅浅打开测了一下，但是我好像忘记调分辨率了？原生分辨率的话感觉帧数不高，这也是可以想见的。应该除了调画质之外，还是要调分辨率吧。不过我后面没测了。呃啊没有空玩。~~也许我的某个朋友会看到这篇文章分享一些自己的体验？~~ 玩 Big Walk 帧数不高，调了两下只有 60 fps 吧。感觉也是调不了分辨率导致的。玩奥日 2 的时候不用调分辨率，我插着电开性能模式很流畅，而且不插着电很很流畅！这个离电性能真的是太 nb 了。

总结：只要调分辨率感觉啥都能玩。

综上可得，这简直是一台完美在外打蔚蓝的电脑！在暑假开始去云南旅游的时候，此电脑可以塞进飞机和动车座位的小桌板；99.9Wh 的电池直接压线带上飞机，如上所说续航特别长（完全可以开静音省电模式也不会掉帧的，真是好游戏）；由于我的蔚蓝键位是 Z 跳 X 抓 C 冲 和 方向键（空洞骑士先入为主了；再往前小时候也从来没有用过 jkil），这意味着我可以非常无脑地按方向键两侧的 PageUp 和 PageDown 来切房间（哪个模组的内容来着，也许是 SpeedRun Tools 吧），手感也很好，不会和旧的那台一样左右键会冲突。

其他外围配置：请输入文本。同样无敌好吗，不无敌我还花联想的溢价买这东西干啥？

tmp: bar.pic, 物理开关摄像头.pic

这个 bar 凸出来虽然没有在原本的设计意图上对我有什么用（至少基于目前有的配件来说），但是非常完美地可以作为单手开合的辅助！优雅，无需多言。上面是有能遮住摄像头的物理小开关的，好评，但是由于一直在用人脸识别登录所以基本上不会关上。摄像头没怎么用过，不知道，那就是不重要。然后还有红外，可以检测到屏幕前人离开自动锁屏 / 暂停视频，然鹅后者好像没怎么测出来过？也许是由于我试图观测了它。薛定谔的暂停。前者由于现在经常会需要 Agent 跑着所以也关掉了，我发现常见的 nosleep / Awake 这些小软件阻止不到这个锁屏。

扬声器我觉得很好。电脑到手立刻严肃播放本地的超时空辉夜姬，外放，虽然感觉八千代的歌声仿佛就是活的！但是直接静音我大概也能听到歌声吧...没救了...

总结：键盘打油是一个问题。触摸板的震感对我没用勉强算是一个问题。然后就没了，真是完美适合我的机器！居然刚好在我高考结束这一届出现，难得我的人生里有赶上好事物诞生的时候！

卧槽啊怎么写了这么多了。大有要写三天的感觉啊。

电脑写了这么多那感觉这篇文章也是要长得离谱啊。感觉文章要写的很长就会想着少写一点，但那是 废物的思维。直接把从介绍电脑改成介绍我现在用的所有数码产品好了！

对手机的硬件参数我是没得讲了，极客湾.link。我主要可以来讲一下我从 iPhone X 转到这台手机上的软件上的使用体验。

这个拍照键先说吧（哇哦，好的设计真是互通呢。）虽然这个调焦距和想象中的一样精度一坨，但是双击打开相机真是个不错的发明！我迅速地练成了从口袋里拿出手机的时候小拇指双击打开相机雷霆抓拍的神奇技能。美式居合，小子。但不得不吐槽的一点是，我拿到的时候发现似乎在黑屏状态下双击是没有反应的。也就是说，你需要结合着拿起手机时自动亮屏的功能才能施展此技能；如果你按早了手机还没亮屏就会失败。这很愚蠢，但是在写这篇文章的时候经测试应该是改好了。

tmp: 拍照键.pic

拿到手机的第一个小时其实有点后悔。情况是这样：
1. AI 功能扑面而来，有一点广告
2. 主界面被乱七八糟的系统应用占据了。我在 iPhone X 上（以及 Windows 上）都是用类似 iOS 滑到最右侧的 App 库 / 开始菜单的全部应用 来启动应用的。我认为这是非常合理且方便的设计：既然有首字母索引，这理论上比你在桌面上费劲心思地排列图标、记忆图标位置，然后在不小心移动了某个图标之后多次误触好的多了。
3. 这东西可比 iPhone X 大多了。有点不适应。
4. 我买之前在买 iPhone 还是 OPPO 之间纠结过。我只是怕了。
   
是时候改变这一切了。首先我很快找到了 ColorOS 系统设置中的“抽屉”功能，立刻这就让我感到惊喜了：这比苹果做的好用。

tmp: 抽屉.pic，颜色选择.pic

然后跟着网上的教程把广告能关的关了，装了一堆常用软件，把 AI 功能基本都关了，然后把没用的软件放到了 ColorOS 的“隐藏应用”功能里。换了壁纸。就差不多了

## 键盘

依旧选了好久。感觉自己由于空洞和蔚蓝都是在笔记本上面打的，试了一下表弟的迈从 K99，也买了些轴换上，感觉自己是无法适应用机械键盘打蔚蓝了；选了选之后狠心买了雷蛇 Joro 键盘，花了 800 RMB 左右吧。但是我又能说什么呢，这个东西又是太符合我的需求了：背光，功能键，轻薄，以及最重要的超矮轴的类似笔记本键盘的手感；此外还有一个叫做 SNAP TAP 的功能，简单来说，就是按住左，再按右，不会同时输入左右（导致游戏里横向的速度向量变成 0）而是会取消左保留右。可以自己选择开关。不过这算是 cheat 了吧？

## 蓝牙耳机

OPPO Enco Air5s。林呜云进大观园了，我之前用的耳机都是什么勾石啊（）

tmp: earphone.pic

我没有办法和同个定位的产品对比吧。一开始也是在 AirPods 和这个里面选，但是价格喵鲨了，既然我不用苹果生态，那 AirPods - OPPO Enco 的 800 块钱差价对应的那些功能直接就消失了啊。

下单时看宣传图觉得外观是那种很廉价的塑料，到手之后发现和我想的完全不一样，是哑光的；也不会很圆润显得老气，有棱有角的。一下子好感度++。

实际体验也很不错，首先生态上其实也不算是有啥很特殊的联动：连接的时候有动画，控制中心可以直接打开设置，各家都有吧，不过确实很方便。在此之上还有很多可夸的点：
1. 降噪和通透都非常可用，降噪在地铁上真的瞬间静音，把耳机在耳朵里动一下方向降噪也会在几秒内很灵敏地跟上；入耳检测也没有任何问题，把耳机摘下来听人说话的时候会自动暂停音视频播放；
2. 按住耳机仓底部充电口旁边的小按钮之后会进入蓝牙配对模式，不会出现“怎么蓝牙找不到这个耳机是不是耳机有问题”这种情况；
3. 可同时连接手机和电脑。虽然输出的音频并不是双端的混合，而是先来后到；此外我先连了手机再电脑开机就自动连上，也会有提示音；
4. 游戏模式有用，至少我体感电脑手机都有用，是能在手机上打音游、在电脑上玩渔力全开的时候开枪感觉不到太大延迟的；
5. 提示音是非常正常的女声，听起来不会有什么不适感。
6. 我只能用半入耳，全入耳感觉耳朵要爆炸了。半入耳是对的。

## 充电头 / 线 / 宝
充电宝是绿联的，2w mAh，没什么好说的。

我买充电线和充电头之前调研了一下，什么协议啊最大电流啊什么什么的；但是忘记了。直接给出结果吧。

充电头是 OPPO 的小方瓶，100W 的版本。送了一根线，可以达到我手机的最大充电速度。（似乎说是 OPPO 手机的这个快充和别家的不太一样，好像是 80W，但是电流比较大，所以用原厂的充的最快；而且看小米的充电头好像是 60W 的。也许吧），支持 SuperVOOC 协议（具体是什么意思呢我也不知道）；然后充电线还额外买了一条绿联的 2m 编织线，经测试这一套头加线是可以给我的电脑充上电的。确实很好用确实很快。
