## 0. 从数列极限到函数极限

| | 数列 | 函数 |
|---|---|---|
| 自变量 | $n\in\mathbb{N}_+$ 离散取值 | $x$ 连续取值 |
| 趋近方式 | 只有 $n\to+\infty$ | 可趋于 $+\infty,\ -\infty,\ \infty$，也可趋于**有限点** $x_0$ |
| 定义语言 | $\varepsilon\text{-}N$：$\forall\varepsilon>0,\exists N,\forall n>N$ | $\varepsilon\text{-}X$（无穷处）／$\varepsilon\text{-}\delta$（$x_0$ 处） |

**对应关系**：实数 $X$ 代替正整数 $N$；$x>X$ 代替 $n>N$。所以数列极限的结论几乎都能"平移"过来。

## 1. 概念与定义

### 1.1 自变量趋于无穷的三种方式

- $x\to+\infty$：$x$ 取正值无限增大；
- $x\to-\infty$：$x$ 取负值且 $\lvert x\rvert$ 无限增大；
- $x\to\infty$：**同时**考察正负两个方向，且 $\lvert x\rvert$ 无限增大。

> **记号约定**（本教材）：$x\to\infty$ 表示同时考察 $x\to+\infty$ 与 $x\to-\infty$；需要防止误解时写成 $\lvert x\rvert\to\infty$。

### 1.2 定义 3.1（$x\to+\infty$ 时的函数极限）

设 $f:[\alpha,+\infty)\to\mathbb{R}$。若存在 $a\in\mathbb{R}$，使

$$\forall\varepsilon>0,\ \exists X\ge\alpha,\ \forall x>X,\quad \lvert f(x)-a\rvert<\varepsilon,$$

则称 $a$ 为 $f(x)$ 当 $x\to+\infty$ 时的极限，记作

$$\lim_{x\to+\infty}f(x)=a .$$

- **几何意义**：无论水平带 $a-\varepsilon<y<a+\varepsilon$ 多窄，图像从某条竖线 $x=X$ 之后都落进带内。
- 其余两种（$f$ 在相应方向的尾部区间有定义）：

$$x\to-\infty:\quad \forall\varepsilon>0,\ \exists X>0,\ \forall x<-X,\ \lvert f(x)-a\rvert<\varepsilon ;$$
$$x\to\infty:\quad \forall\varepsilon>0,\ \exists X>0,\ \forall \lvert x\rvert>X,\ \lvert f(x)-a\rvert<\varepsilon .$$

- **两端归并**：
$$\lim_{x\to\infty}f(x)=a \iff \lim_{x\to+\infty}f(x)=\lim_{x\to-\infty}f(x)=a .$$

### 1.3 定义 3.2（$x\to x_0$ 时的函数极限）

设 $f$ 在 $x_0$ 的**某个去心邻域**内有定义。若存在 $a\in\mathbb{R}$，使

$$\forall\varepsilon>0,\ \exists\delta>0,\quad 0<\lvert x-x_0\rvert<\delta \Rightarrow \lvert f(x)-a\rvert<\varepsilon,$$

则称 $a$ 为 $f(x)$ 当 $x\to x_0$ 时的极限，记作 $\displaystyle\lim_{x\to x_0}f(x)=a$。

**为什么是去心邻域**：极限只研究 $x$ 接近 $x_0$ 时函数值的**趋势**，与 $f(x_0)$ 是否存在、等于多少**无关**。

- 例：$f(x)=\dfrac{x^2-1}{x-1}\ (x\ne 1)$，即使另行规定 $f(1)=0$，仍有 $\displaystyle\lim_{x\to 1}f(x)=2$。
- 几何意义：宽 $2\delta$ 的竖直带（挖掉中线）内的图像，全部落入长方形 $(x_0-\delta,x_0+\delta)\times(a-\varepsilon,a+\varepsilon)$。

### 1.4 单侧极限

$$\lim_{x\to x_0^-}f(x)=a \iff \forall\varepsilon>0,\ \exists\delta>0:\ x_0-\delta<x<x_0 \Rightarrow \lvert f(x)-a\rvert<\varepsilon ;$$
$$\lim_{x\to x_0^+}f(x)=a \iff \forall\varepsilon>0,\ \exists\delta>0:\ x_0<x<x_0+\delta \Rightarrow \lvert f(x)-a\rvert<\varepsilon .$$

**双侧极限存在的判别**：

$$\lim_{x\to x_0}f(x)=a \iff \lim_{x\to x_0^-}f(x)=\lim_{x\to x_0^+}f(x)=a .$$

于是：**左、右极限有一个不存在，或都存在但不相等 $\Rightarrow$ 极限不存在**。

- 典型例：$\operatorname{sgn}x$ 在 $0$ 处，$\lim_{x\to 0^-}\operatorname{sgn}x=-1$，$\lim_{x\to 0^+}\operatorname{sgn}x=1$，故 $\lim_{x\to 0}\operatorname{sgn}x$ 不存在。

### 1.5 函数趋于无穷

设 $f$ 在 $x_0$ 的某去心邻域内有定义。若

$$\forall M>0,\ \exists\delta>0,\quad 0<\lvert x-x_0\rvert<\delta \Rightarrow \lvert f(x)\rvert>M,$$

则称 $f(x)$ 在 $x\to x_0$ 时**趋于无穷**，记 $\displaystyle\lim_{x\to x_0}\lvert f(x)\rvert=+\infty$。

- **注意**：这只表示函数值的**模**趋于无穷，**符号可以改变**。
- $\lim f(x)=+\infty$：把 $\lvert f(x)\rvert>M$ 换成 $f(x)>M$；$-\infty$ 换成 $f(x)<-M$。
- 教材把"模趋于无穷"简写为 $\lim_{x\to x_0}f(x)=\infty$；本课件统一用绝对值形式以免与 $+\infty$ 混淆。

### 1.6 邻域记法速查

| 记号 | 含义 |
|---|---|
| $U(x_0,\delta)$ | $(x_0-\delta,\ x_0+\delta)$ |
| $\mathring{U}(x_0,\delta)$ | $0<\lvert x-x_0\rvert<\delta$（去心） |
| $U(+\infty,M)$ | $(M,+\infty)$ |
| $U(-\infty,M)$ | $(-\infty,-M)$ |
| $U(\infty,M)$ | $(-\infty,-M)\cup(M,+\infty)$ |

定义 3.1 的邻域写法：$\forall\varepsilon>0,\ \exists X>0$，使 $\forall x\in U(+\infty,X)$ 恒有 $f(x)\in U(a,\varepsilon)$。

## 2. 定理与性质（本节的"工具库"）

| 定理 | 内容 | 主要用途 |
|---|---|---|
| **3.1 Heine 归并原理** | $\lim\limits_{x\to x_0}f(x)=a$ 的充要条件是：对 $\mathring{U}(x_0)$ 内**任意**数列 $\{x_n\}$（$x_n\ne x_0,\ x_n\to x_0$），都有 $f(x_n)\to a$ | 函数极限 $\leftrightarrow$ 数列极限；**证明极限不存在**；也给性质定理提供统一证法 |
| **3.2 唯一性** | 极限存在则极限值唯一 | 理论证明、反证 |
| **3.2 局部有界性** | 若 $\lim\limits_{x\to x_0}f(x)=a$，则 $\exists M>0,\ \exists\delta>0$，使 $0<\lvert x-x_0\rvert<\delta$ 时 $\lvert f(x)\rvert\le M$ | 估计、放大不等式 |
| **3.3 局部保号性** | 若 $\lim f(x)=a\ne 0$，则某去心邻域内 $f(x)$ 与 $a$ 同号；特别 $a>0$ 时可找到 $q>0$ 使 $f(x)\ge q>0$ | 判断符号、夹逼的起点 |
| **3.3 局部保序性** | 局部恒有 $f(x)\le g(x)$，且 $\lim f=a,\ \lim g=b$，则 $a\le b$ | 不等式取极限 |
| **3.3 夹逼性** | 局部 $f(x)\le\varphi(x)\le g(x)$，且 $\lim f=\lim g=a$，则 $\lim\varphi=a$ | **求极限主力工具** |
| **3.4 有理运算法则** | 设 $\lim f=a,\ \lim g=b$，则 $\lim(f\pm g)=a\pm b$，$\lim(fg)=ab$，$\lim\dfrac fg=\dfrac ab\ (b\ne 0)$；线性：$\lim(\alpha f+\beta g)=\alpha a+\beta b$ | 计算极限的**前提** |
| **3.5 复合函数极限** | 若 $\lim\limits_{x\to x_0}g(x)=u_0$，$\lim\limits_{u\to u_0}f(u)=a$，且在某去心邻域内恒有 $g(x)\ne u_0$，则 $\lim\limits_{x\to x_0}f[g(x)]=a=\lim\limits_{u\to u_0}f(u)$ | **变量代换** $u=g(x)$ |
| **3.6 单调有界准则** | ① $f$ 在 $[a,+\infty)$ 单调增有上界（或单调减有下界）$\Rightarrow \lim\limits_{x\to+\infty}f$ 存在且有限；② $f$ 在区间 $I$ 上单调 $\Rightarrow$ $I$ 的每个内点处左右极限都存在；③ $f$ 在 $(a,a+\delta)$ 上单调有界 $\Rightarrow \lim\limits_{x\to a^+}f$ 存在 | 判断存在（不必求值） |
| **3.7 Cauchy 收敛原理** | $\lim\limits_{x\to x_0}f$ 存在 $\iff \forall\varepsilon>0,\exists\delta>0,\forall x_1,x_2\in\mathring{U}(x_0,\delta),\ \lvert f(x_1)-f(x_2)\rvert<\varepsilon$ | 判断存在，**不需要预先知道极限值** |

### 2.1 使用时必须注意的前提

1. **有理运算法则要求拆开后每个极限都存在**。写成
   $\lim\limits_{x\to 0}\dfrac{\sin x}{x}=\dfrac{\lim\sin x}{\lim x}=\dfrac 00$ 是**错误**的（习题 1.3 第 9 题专考这个）。
2. **保号性、保序性、夹逼性都是"局部"的**，只在 $x_0$ 的某个去心邻域内成立。
3. **定理 3.5 的去心条件不能丢**。反例：
   $$f(u)=\begin{cases}1,&u\ne 0\\0,&u=0\end{cases},\qquad g(x)\equiv 0 .$$
   则 $\lim\limits_{x\to 0}g(x)=0$，$\lim\limits_{u\to 0}f(u)=1$，但 $f[g(x)]=f(0)\equiv 0$，故 $\lim\limits_{x\to 0}f[g(x)]=0\ne 1$。
   （原因：外层极限不涉及 $f(0)$，而这里 $g(x)\equiv 0$ 违反去心条件。）
4. **保序性不能加强为严格不等号**：局部 $f<g$ 只能推出 $a\le b$。

### 2.2 七个定理的证明思路（考试爱问"怎么证"）

| 定理 | 证明思路 |
|---|---|
| 3.1 Heine（必要性） | **"搭桥"**：把定义 3.2 给出的 $\delta$ 当作数列极限定义里的 $\varepsilon$ 用，把 $\lim\limits_{x\to x_0}f=a$ 与 $x_n\to x_0$ 联系起来 |
| 3.1 Heine（充分性） | 反证：若 $f$ 不以 $a$ 为极限，则 $\exists\varepsilon_0>0,\forall\delta>0,\exists x:0<\lvert x-x_0\rvert<\delta$ 且 $\lvert f(x)-a\rvert\ge\varepsilon_0$；取 $\delta_n=1/n$ 构造出 $x_n\to x_0$ 但 $f(x_n)\not\to a$ 的数列，矛盾 |
| 3.2(1) 唯一性 | Heine 归并 + 数列极限唯一性 |
| 3.2(2) 局部有界 | 取 $\varepsilon=1$，三角不等式 $\lvert f(x)\rvert\le\lvert f(x)-a\rvert+\lvert a\rvert\le 1+\lvert a\rvert$ |
| 3.3 夹逼性 | Heine 归并 + 数列夹逼性 |
| 3.4 四则运算 | Heine 归并 + 数列四则运算 |
| 3.5 复合函数 | 两级 $\varepsilon$-$\eta$-$\delta$ 套用，取 $\delta=\min\{\delta_0,\delta_1\}$ 保证 $0<\lvert u-u_0\rvert$ |
| 3.6 单调有界 | 用**上确界的 $\varepsilon$ 刻画**：$\sup f=a$ 表示 $\forall\varepsilon>0,\exists x_0$ 使 $f(x_0)>a-\varepsilon$；再由单调性夹住 |
| 3.7 Cauchy（必要性） | 三角不等式 $\lvert f(x_1)-f(x_2)\rvert\le\lvert f(x_1)-a\rvert+\lvert f(x_2)-a\rvert$ |
| 3.7 Cauchy（充分性） | 任取 $x_n\to x_0$，由条件得 $\{f(x_n)\}$ 满足数列 Cauchy 原理故收敛；再证任意数列极限相同（反证 + 构造交错数列 $x_1,\bar x_1,x_2,\bar x_2,\dots$） |

## 3. 两个重要极限（必背 + 会变形）

$$\boxed{\lim_{x\to 0}\frac{\sin x}{x}=1}\qquad\qquad \boxed{\lim_{x\to\infty}\Bigl(1+\frac1x\Bigr)^{x}=e}\iff \boxed{\lim_{x\to 0}(1+x)^{1/x}=e}$$

### 3.1 第一个重要极限

**证明（几何夹逼）**：对 $0<x<\dfrac\pi 2$，作单位圆，由面积比较

$$S_{\triangle AOB}<S_{\text{扇形}AOB}<S_{\triangle AOC}\ \Longrightarrow\ \sin x<x<\tan x\ \Longrightarrow\ \cos x<\frac{\sin x}{x}<1 .$$

不等式各项都是偶函数，故对 $0<\lvert x\rvert<\dfrac\pi 2$ 都成立；再用夹逼性与 $\lim\limits_{x\to 0}\cos x=1$ 即得。

- **必须是弧度制**（推导用了弧长公式 $s=xR$），后面所有三角求导公式都依赖它。
- 副产品：由 $\lvert\sin t\rvert\le\lvert t\rvert$ 得
  $$0\le 1-\cos x=2\sin^2\frac x2\le \frac{x^2}{2}\ \Longrightarrow\ \lim_{x\to 0}\cos x=1 .$$
- 应用：弦长与弧长之比 $\dfrac{AB}{\widehat{AB}}=2\sin\frac x2\Big/x\to 1$，即"无穷小弧与弦等价"。

### 3.2 第二个重要极限

**证明（取整 + 夹逼）**：对 $x>1$，令 $n=\lfloor x\rfloor$，则 $n\le x<n+1$，于是

$$\Bigl(1+\frac{1}{n+1}\Bigr)^{n}<\Bigl(1+\frac1x\Bigr)^{x}<\Bigl(1+\frac1n\Bigr)^{n+1}.$$

记两侧为 $L_n=\dfrac{a_{n+1}}{1+\frac1{n+1}}$（$a_n=(1+1/n)^n$）与 $U_n=a_n\bigl(1+\frac1n\bigr)$，由数列版极限 $\lim a_n=e$ 与四则运算得 $\lim L_n=\lim U_n=e$。对任意 $\varepsilon>0$ 取 $N$，再取 $X=N+1$，则 $x>X$ 时 $n=\lfloor x\rfloor>x-1>N$，两侧估计同时成立，故得 $\lim\limits_{x\to+\infty}(1+1/x)^x=e$。

- **$x\to-\infty$**：令 $t=-x-1>0$，则 $\Bigl(1+\frac1x\Bigr)^{x}=\Bigl(1+\frac1t\Bigr)^{t}\Bigl(1+\frac1t\Bigr)\to e\cdot 1=e$。
- **$x\to 0$**：令 $u=1/x$，得 $\lim\limits_{u\to 0}(1+u)^{1/u}=e$。
- 类型：底数趋于 $1$、$\lvert$指数$\rvert$ 趋于 $\infty$，属于 $1^{\infty}$ 型不定式。

## 4. 有界性与确界（3.4 的铺垫）

- **上（下）界**：$\exists M$，使 $\forall x\in A,\ f(x)\le M$（或 $f(x)\ge m$）。
- **有界**：$\exists M>0$，使 $\forall x\in A,\ \lvert f(x)\rvert\le M$。
- **上确界刻画**：$s=\sup\limits_{x\in A}f(x)$ $\iff$ ① $\forall x\in A,\ f(x)\le s$；② $\forall\varepsilon>0,\ \exists x_\varepsilon\in A,\ f(x_\varepsilon)>s-\varepsilon$。下确界把不等号反向。

## 5. 不定式清单（本节遇到的五种）

$$0/0,\qquad \infty/\infty,\qquad \infty-\infty,\qquad 0\cdot\infty,\qquad 1^{\infty}$$

> **"不定式"只描述"直接代入得到的形式"**，绝不表示极限不存在或等于某个值，必须变形后再算。

| 类型 | 常用处理 |
|---|---|
| $0/0$ | 因式分解消零因子；有理化；等价无穷小代换（第 4.3 段） |
| $\infty/\infty$ | 分子分母同除以最高次幂 |
| $\infty-\infty$ | 通分或有理化，化为商的形式 |
| $0\cdot\infty$ | 改写成商 $0\big/(1/\infty)$，或变量代换 |
| $1^{\infty}$ | 凑 $(1+\square)^{1/\square}$，或用第二个重要极限 |

## 7. 课本第 3 节例题：逐题方法总结

### 7.1 用定义证明极限（$\varepsilon$-$X$ / $\varepsilon$-$\delta$）

| 例题 | 题目 | 方法要点 |
|---|---|---|
| **例 3.1** | $\lim\limits_{x\to+\infty}\sin\dfrac1x=0$ | **放大不等式**：$\left\lvert\sin\frac1x-0\right\rvert\le\frac1x$，令 $\frac1x<\varepsilon$，取 $X=\frac1\varepsilon$ |
| **例 3.2** | $\lim\limits_{x\to 2}\dfrac{x^2-4}{x-2}=4$ | 先**约分消零因子**：$\left\lvert\frac{x^2-4}{x-2}-4\right\rvert=\lvert x-2\rvert$，取 $\delta=\varepsilon$ |
| **例 3.3** | $\lim\limits_{x\to 2}\dfrac{x-2}{x^2-4}=\dfrac14$ | 目标 $=\dfrac{\lvert x-2\rvert}{4\lvert x+2\rvert}$，**先限制 $\lvert x-2\rvert<1$** ⇒ $1<x<3$ ⇒ $\lvert x+2\rvert>3$ ⇒ 放大为 $\frac{\lvert x-2\rvert}{12}$，取 $\delta=\min\{1,12\varepsilon\}$ |
| **例 3.9** | $\lim\limits_{x\to 0}e^x=1$，$\lim\limits_{x\to x_0}a^x=a^{x_0}\ (a>0)$ | $e^x-1<\varepsilon$ 反解得 $\delta=\ln(1+\varepsilon)$；$x\to 0^-$ 用 $e^x=1/e^{-x}$ 取倒数；再证 $a^x\to 1$，最后 $a^x=a^{x_0}a^{x-x_0}$ 用**复合函数法则**（令 $u=x-x_0$） |

**$\varepsilon$-$\delta$ 证明三步模板**（"没思路"时照这个走）：

1. **分析**：任给 $\varepsilon>0$，要使 $\lvert f(x)-a\rvert<\varepsilon$——
   - 能等价变形出 $\lvert x-x_0\rvert<\varphi(\varepsilon)$：直接取 $\delta=\varphi(\varepsilon)$；
   - 不能就直接放大成 $\lvert f(x)-a\rvert\le C\lvert x-x_0\rvert$（$C$ 为常数）；
   - $C$ 里含 $x$ 时，**先把 $x$ 限制在 $\lvert x-x_0\rvert<1$**，把它换成常数 $C_0$。
2. **取 $\delta$（或 $X$）**：$\delta=\varphi(\varepsilon)$ 或 $\delta=\min\{1,\ \varepsilon/C_0\}$。
3. **综合**：正写"当 $0<\lvert x-x_0\rvert<\delta$ 时，$\lvert f(x)-a\rvert\le\cdots<\varepsilon$"，收尾"由定义知 $\lim=a$"。

书写提醒：定义 3.2 的前提是"$f$ 在 $x_0$ 的某去心邻域内有定义"，$\delta$ 要选得足够小以保证 $x\in\mathring{U}(x_0)$。

### 7.2 证明极限不存在

| 例题 | 题目 | 方法 |
|---|---|---|
| **例 3.4** | 证明 $x\to 0$ 时 $f(x)=\sin\dfrac1x\ (x\ne 0)$ 的极限不存在 | **Heine 定理**：取两条都趋于 $0$ 的数列 $x_n'=\frac{1}{n\pi}$（$f\to 0$）与 $x_n''=\frac{1}{2n\pi+\frac\pi2}$（$f\to 1$），同一函数沿不同路径趋于不同值 |

配套套路：

- **左右极限法**：分别求 $\lim\limits_{x\to x_0^-}$ 与 $\lim\limits_{x\to x_0^+}$，不相等（或其中一个不存在）$\Rightarrow$ 极限不存在（如 $\operatorname{sgn}x$）。
- **两条路径法（Heine）**：找两个数列（路径）。
- **Cauchy 原理法**：找 $\varepsilon_0$ 与任意接近的两点使 $\lvert f(x_1)-f(x_2)\rvert\ge\varepsilon_0$（$\sin\frac1x$ 在任意小邻域内既能取 $1$ 又能取 $-1$）。
- **无界 $\Rightarrow$ 极限不存在**（有限极限必局部有界）。

### 7.3 求极限：按不定式类型选方法

| 例题 | 类型 | 方法要点 |
|---|---|---|
| **例 3.5** $\lim\limits_{x\to 1}\dfrac{x^2-1}{x^3-1}$ | $0/0$ | **因式分解、约掉零因子** $(x-1)$，得 $\dfrac{x+1}{x^2+x+1}\to\dfrac23$，再用四则运算 |
| **例 3.6** $\lim\limits_{x\to+\infty}\dfrac{x^2+2x+5}{x^2+x+4}$ | $\infty/\infty$ | **分子分母同除以最高次幂** $x^2$，$1/x,1/x^2\to 0$ |
| **例 3.7** $\lim\limits_{x\to 2}\Bigl(\dfrac1{x-2}-\dfrac{12}{x^3-8}\Bigr)$ | $\infty-\infty$ | **通分**化归为 $0/0$，再消零因子：$\dfrac{x+4}{x^2+2x+4}\to\dfrac12$ |
| **例 3.8** 证明 $\lim\limits_{x\to 0}\cos x=1$ | 证明 | **半角公式 + 夹逼**：$0\le 1-\cos x=2\sin^2\frac x2\le\frac{x^2}{2}\to 0$；再 $\cos x=1-(1-\cos x)$ 用四则运算 |
| **例 3.10** $\lim\limits_{x\to 0}\dfrac{\tan x}{x}$ | 重要极限 | **拆成乘积**：$\dfrac{\sin x}{x}\cdot\dfrac{1}{\cos x}\to 1\cdot 1$ |
| **例 3.11** $\lim\limits_{x\to 0}\dfrac{1-\cos x}{x^2}$ | 重要极限 | **半角公式化归**：$=\dfrac12\Bigl(\dfrac{\sin(x/2)}{x/2}\Bigr)^2$，代换 $t=\frac x2$，得 $\dfrac12$ |
| **例 3.12** $\lim\limits_{x\to\infty}x\arcsin\dfrac nx=n$ | $0\cdot\infty$ | **变量代换** $\arcsin\frac nx=t\Rightarrow \sin t=\frac nx\Rightarrow x=\frac{n}{\sin t}$，化为 $n\cdot\dfrac{t}{\sin t}\to n$；代换后需说明 $t\to 0$（由 $\lvert t\rvert<\frac\pi2$ 的单调性） |
| **例 3.13** $\lim\limits_{x\to\infty}\Bigl(1-\dfrac2x\Bigr)^x$ | $1^{\infty}$ | **凑标准形**：令 $-\frac2x=\frac1t$，即 $x=-2t$，得 $\Bigl[\bigl(1+\frac1t\bigr)^{t}\Bigr]^{-2}\to e^{-2}$ |
| **例 3.14** $\lim\limits_{x\to 0}(1+x)^{1/x}$ | $1^{\infty}$ | 令 $\frac1x=t$，化为 $\bigl(1+\frac1t\bigr)^t\to e$；此式**可直接当公式用** |

### 7.4 本节其它理论证据点

- 例 3.5–3.7 之后，课本明确区分了"**不定式**"与"极限不存在"。
- 定理 3.5 的应用示例：$\lim\limits_{x\to 1}\cos(x^3+x-2)$，令 $u=x^3+x-2$；因 $(x-1)(x^2+x+2)\ne 0\ (x\ne 1)$，去心条件满足。
- 定理 3.6 的证明用**确界**；定理 3.7 用 **Heine + 数列 Cauchy + 反证**。

## 8. "看到什么 ↦ 想到什么"（解题思维对照表）

| 题目长这样 | 第一反应 |
|---|---|
| "用定义证明 $\lim=a$" | 上 $\varepsilon$-$X$/$\varepsilon$-$\delta$ 三步模板；必要时先限制邻域再放大 |
| "证明极限不存在" | 左右极限 / 两条数列路径（Heine）/ Cauchy / 无界 |
| 直接代入得 $0/0$ | 因式分解、有理化、等价无穷小 |
| 直接代入得 $\infty/\infty$ | 同除最高次幂（后期：洛必达） |
| 直接代入得 $\infty-\infty$ | 通分、有理化 |
| 直接代入得 $0\cdot\infty$ | 写成商 $0/(1/\infty)$，或变量代换 |
| 直接代入得 $1^{\infty}$ | 凑 $(1+\square)^{1/\square}$，或化为 $e^{\lim \square\ln u}$（$u$ 为底数） |
| 出现 $\dfrac{\sin\square}{\square}$，$\square\to 0$ | 凑第一个重要极限（整体代换） |
| 出现 $(1+\square)^{1/\square}$ | 第二个重要极限（$\square$ 可以是 $x,\frac1x,-\frac2x$…） |

| 递推式或单调函数求极限值 | 先用单调有界证存在，再对递推式两边取极限解方程 |

## 9. 易错点清单

1. **用四则运算法则前必须确认每个极限都存在**：
   $\lim\dfrac{\sin x}{x}=\dfrac{\lim\sin x}{\lim x}=\dfrac00$ 是错的。
2. **乘积法则不能凭空拆**：$\lim x\sin\frac1x=\lim x\cdot\lim\sin\frac1x$ 错（后者不存在）。
3. **$x\to\infty$ 是两个方向**，$x\to x_0$ 要检查左右两侧。
4. **去心邻域不能写成含心**：$0<\lvert x-x_0\rvert<\delta$，否则 $f(x_0)$ 无定义时定义式无意义；且会把
   $f(x)=\begin{cases}2,&x\ne 1\\ -1,&x=1\end{cases}$ 在 $x\to 1$ 的极限误判。
5. **保号性/保序性只局部成立**，且保序性只能是 $\le$。
6. **复合函数代换**：必须保证 $g(x)\ne u_0$。
7. **$\lim f(x)=\infty$** 与 $\lim f(x)=+\infty$ 不同（前者符号可变）。
8. **$1^{\infty}$、$0/0$ 不是数**，不能直接写结果。
9. $\delta$ 与 $x$ 无关（只与 $\varepsilon$ 有关），这是定义的关键；但 $\delta$ **可以**随 $\varepsilon$ 变化。

## 10. 必背工具结论（可直接引用）

$$\lim_{x\to 0}\frac{\sin x}{x}=1,\qquad \lim_{x\to 0}\frac{\tan x}{x}=1,\qquad \lim_{x\to 0}\frac{1-\cos x}{x^2}=\frac12,$$
$$\lim_{x\to\infty}\Bigl(1+\frac1x\Bigr)^x=\lim_{x\to 0}(1+x)^{1/x}=e,\qquad \lim_{x\to\infty}\Bigl(1-\frac2x\Bigr)^x=e^{-2},$$
$$\lim_{x\to 0}e^x=1,\qquad \lim_{x\to 0}a^x=1\ (a>0),\qquad \lim_{x\to x_0}a^x=a^{x_0},$$
$$\lim_{x\to 0}\cos x=1,\qquad \lim_{x\to 0}\frac{1-\cos x}{x^2}=\frac12,\qquad 0\le 1-\cos x\le\frac{x^2}{2},\qquad \lvert\sin x\rvert\le\lvert x\rvert .$$

有理分式在无穷处的口诀：分子分母**次数相等**取系数比；**分母次数高**极限为 $0$；**分子次数高**则发散为 $\infty$。
